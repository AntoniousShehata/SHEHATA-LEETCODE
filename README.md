## 🛠️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/AntoniousShehata/SHEHATA-LEETCODE.git
cd SHEHATA-LEETCODE
```

### 2. (Optional) Create a Virtual Environment
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate
```

### 3. Run Any Solution
```bash
python <path-to-solution-file>
# Example:
python arrays_hashing_two_pointers/container_with_most_water.py
```
